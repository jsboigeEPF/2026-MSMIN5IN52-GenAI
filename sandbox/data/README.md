# Provenance des données Data ES

`equipements_sportifs_cachan.json` est un échantillon de démonstration de
trois installations de la commune de Cachan (code INSEE 94016). Les champs ont
été sélectionnés et reformattés pour ce projet ; ce fichier n'est pas une
réplique complète du jeu source.

- **Jeu source :** [Data ES — Recensement des équipements sportifs et lieux de pratique (Complet)](https://www.data.gouv.fr/datasets/data-es-recensement-des-equipements-sportifs-et-lieux-de-pratique-complet-1)
- **Producteur :** ministère chargé des Sports.
- **Licence :** Licence Ouverte / Open Licence 2.0.
- **Date de préparation de l'échantillon :** 25 octobre 2026 (voir les métadonnées du JSON).
- **Attribution :** « Source : Ministère chargé des Sports, Data ES. Extrait sélectionné et reformatté pour ce projet. »

Data ES est une base nationale mise à jour régulièrement. L'échantillon de ce
dépôt est un instantané statique : il ne se synchronise pas avec le jeu source
et peut ne plus refléter les données les plus récentes. Consulter la page du jeu
source pour les données actuelles, les conditions complètes de licence et la
méthodologie.
